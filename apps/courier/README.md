# SprintGo — تطبيق المناديب «كابتن» (React + Capacitor)

تطبيق الكابتن (المندوب) بنفس هوية SprintGo، مبني بـ React + Vite + TypeScript +
Tailwind v4 ومغلّف بـ Capacitor لإنتاج APK. عربي RTL، سياق دمياط، عملة جنيه.

## التشغيل محلياً

```bash
cd apps/courier && ./node_modules/.bin/vite
```

يفتح على `http://localhost:5176` ويوجّه `/api` لسيرفر NestJS على `localhost:4000`.

## الشاشات

- **الرئيسية** — سويتش أونلاين/أوفلاين، أرباح اليوم (توصيلات + كاش)، التوصيلة الجارية.
- **وصول طلب** — عدّاد تنازلي (30 ثانية)، أرباح التوصيلة، الاستلام→التسليم، قبول/رفض.
- **التوصيلة النشطة** — خريطة بمسار، زر بيتقدّم بالمراحل (توجّه→استلمت→في الطريق→تم
  التسليم)، اتصال، وتحصيل الكاش.
- **التوصيلات** — الجارية + المكتملة اليوم بأجر كل واحدة.
- **الأرباح** — اليوم/الأسبوع + رسم بياني + تفصيل (أجر/إكراميات/حوافز).
- **حسابي** — التقييم والمركبة، كاش للتوريد، الإعدادات، الخروج.

نظام التصميم مشترك مع تطبيق العميل (`src/index.css`).

## بناء الـ APK

نفس الـ workflow `.github/workflows/android-apk.yml` يبني تطبيقي العميل والمندوب معاً
(matrix). آرتيفاكت المندوب اسمه `sprintgo-courier-apk`.
